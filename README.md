# QQ 自动回复机器人（OneBot v11 + DeepSeek）

让你的 QQ 号自己回消息。带**性格设定**、**群聊插话判断**、**表情包**、**小本本**（对每个人的印象笔记）、**掉线自动告警**。

> 📦 **这个包是「全离线包」，开箱即用。**
> **Node.js 和 NapCat 都已经打包在里面**，不用另外下载、不用 `npm install`、不用配环境。
> 唯一需要你电脑上自己有的东西是：**Windows 10/11（64 位）** + **PC 版 QQ**（因为 NapCat 要注入它）。
>
> 拿到压缩包 → 解压 → **双击 `一键启动.bat`** → 回答 3 个问题 → 剩下的它自己搞定。

## 一、双击一个文件就能跑

**前提只有两个**：Windows 10/11（64 位）、电脑上装好了 **PC 版 QQ**。

**① 解压**
把压缩包解压到一个**路径里没有中文和空格**的地方，比如 `D:\qqbot\`。
（路径带中文通常也没事，但极少数情况会让脚本找不到文件，放英文路径最稳。）

**② 双击 `一键启动.bat`**

然后就没你什么事了。它会自己按顺序做：

1. 弹一个「用户账户控制」窗口 → 点 **是**（NapCat 必须把模块注入 QQ 进程）
2. 自检 Node.js、NapCat、QQ 是否齐全
3. 第一次跑会问你几个问题：

| 问题 | 填什么 |
|---|---|
| 机器人 QQ 号 | 你要挂机器人那个号（建议小号） |
| 你自己的 QQ 号（主人） | 你的常用号。填了才能用 `/状态` `/闭嘴` 这些指令 |
| DeepSeek API Key | 去 [platform.deepseek.com](https://platform.deepseek.com) 申请（新账号有免费额度）。**也可以先回车跳过**，之后再在面板里填 |
| 要不要在群里自动回复 | 填 `y` 或 `n` |

4. 自动生成 `config.json` + NapCat 连接配置 + 免扫码启动脚本
5. 启动 QQ + NapCat，等它连上
6. 启动机器人和控制面板
7. 自动打开浏览器面板 `http://127.0.0.1:4399`
8. 它自己那个窗口 10 秒后自动关闭

**第一次需要扫码**：NapCat 起来后桌面上会有一个 QQ 登录窗口，用**手机 QQ**（登录机器人那个号）扫它，点「允许登录」。
扫完它自己就连上了，**以后不用再扫**（本地登录态会记住）。

看到这两行就成功了：

```
[onebot] connected · ws://127.0.0.1:3001
[onebot] ready — listening for messages.
```

> 💡 **留下的两个黑窗口都别关**：「QQ 机器人控制面板」是机器人在跑，「NapCat Auto Login」是连 QQ 的。关了机器人就停了。
>
> 💡 **以后每次开电脑，还是只双击 `一键启动.bat`** —— 已经在跑的东西它会自动跳过，不会重复启动。
>
> 💡 想全部停掉：双击 `force-stop.bat`。

## 三、功能清单

### 性格

- **可视化编辑**：面板「② AI 性格」页，拖滑块调 幽默/话多/亲切/正式/爱怼/表情 六个维度
- **预设 + 自定义**：内置 `buddy`（朋友）/ `sweet`（温柔）/ `tsundere`（傲娇）/ `cold`（高冷），也能完全自定义
- **口头禅 / 禁用词**：让它偶尔蹦出你的口头禅，或禁止某些词
- **自我认知**：可以让它有具体人设（比如某个角色），面板里填

### 聊天

- **回复拆段**：一条回复拆成几条短消息连发（像真人打字），间隔可调
- **联网搜索**：遇到不知道的事可以自己查
- **视觉**：**真的能看图**（把图发给它，它会描述/吐槽）
- **回复自己**：连你自己在聊天框里打的字也回（默认关）
- **最短长度**：太短的消息会自动跟相邻的合并，不会只蹦一个字
- **上下文**：记住最近几轮对话

### 群聊

- **被 @ 必回**
- **自主插话**：没被 @ 时让 AI 自己判断该不该接话
- **积极程度 1~5**：1=几乎不插话，5=很爱接话（面板上是下拉框，选文字就行）
- **按群白名单**：只回指定的群
- **每小时上限**：防止在群里刷屏被踢

### 表情包

- **自动发表情包**：AI 根据语境挑一张发
- **情绪标签**：按文件夹名 / 文件名 / `[方括号]` 自动识别情绪
- **自动打标签**：新丢进去的图用 AI 识别情绪并缓存
- **抓群里的表情包**：别人发的图自动收进库，去重、能用
- **涩图拦截**：图片和文字都拦，命中后骂回去且不收进库

### 小本本（印象笔记）

- 记每个人的**记仇 / 记好 / 性格印象 / 事件**
- **只认人不认环境**：按 QQ 号存，私聊和群聊共用一本
- **有事才记**：只在情绪波动或标志性事件时写
- **防捏造**：必须有原话出处才允许记
- **说话策略**：自动总结「对这个人该怎么说话」
- 面板「⑥ 小本本」页可看、可改、可删

### 运维

- **掉线告警**：检测到掉线就弹窗 + 写桌面文件 + 声音提醒
- **掉线诊断**：自动抓现场快照（进程/端口/系统事件），事后能查原因
- **自动重启**：授权后可自动重启 QQ + NapCat
- **防睡眠**：机器人运行期间不让电脑睡（睡了 NapCat 会变空壳）
- **余额提醒**：API 余额快见底时通知你
- **聊天录制 + 导出**

## 五、NapCat 与 QQ

### 已经内置了，不用你装

包里 `napcat/` 目录就是一份完整的 **NapCat.Shell（Windows x64 精简版）**——
只保留了 Windows 用得到的原生模块，其它平台（macOS / Linux / ARM）的几十兆都删掉了，功能不受影响。

### 你只需要装 PC 版 QQ

NapCat 是「寄生」在 QQ 上的（它把自己注入 QQ 进程，借 QQ 的网络和协议收发消息），所以：

**必须先装好 PC 版 QQ，并且用机器人那个号登录过一次。**

下载：<https://im.qq.com/pcqq>

> 💡 `restart-qq-napcat.bat` 会自己去注册表里找 QQ 装在哪，不用你填路径。

### 免扫码登录（已自动配好）

第一次扫码登录成功后，**下次通常就不用再扫了**。
向导生成的 `napcat/launcher-autologin.bat` 已经把你的 QQ 号写进去了，启动时带 `-q 你的QQ号` 走快速登录。

> 💡 免扫码能不能成，取决于腾讯是否还保留本机登录态。
> **长期没登录 / 换了网络 / 清了 QQ 缓存**时，还是得重新扫一次码，这个绕不过去。

### 万一想手动改连接

NapCat 的 OneBot 配置在 `napcat/config/onebot11_<你的QQ>.json`，向导已经配好了：

| 项 | 值 |
|---|---|
| 类型 | **正向 WebSocket**（WebSocket 服务器） |
| Host | `127.0.0.1` |
| Port | `3001` |
| 报文格式 | `JSON` |
| Token | 留空（要和 `config.json` 里的 `onebot.accessToken` 一致） |

NapCat 自己的 WebUI 在 `http://127.0.0.1:6099`（**一般用不到**，正常流程不会让你打开它）。

> **如果确实被要求填 WebUI 的 Token**：不用去翻文件 ——
> 打开控制面板「① 登录与配置」页，里面有一栏
> **「NapCat WebUI 登录 Token」**，旁边就是「复制」按钮，复制粘贴即可。
> 那一串存在 `napcat/config/webui.json` 的 `token` 字段里，面板只是帮你读出来了。

## 六、配置说明

配置在 `config.json`（向导自动生成）。`config.example.json` 是带全中文注释的模板 ——
**所有选项都在里面**，每一项的 `_说明` 字段就是注释。想改什么，照着自己那份 `config.json` 加键就行。

> 💡 面板上能改的（API Key、性格、群聊开关…）**优先用面板改**，它会直接写回 `config.json`。
> 面板上改不了的（比如双通道、时间窗）才手动编辑文件，改完要**重启机器人**才生效。

**几个最容易踩的坑**：

| 现象 | 原因 |
|---|---|
| 机器人完全不回复 | `bot.allowedUsers` 是空的 `[]` → 填 `["*"]` 或具体 QQ 号 |
| 指令都没反应 | `bot.admin` 没填 → 填你自己的 QQ 号（向导已经帮你填了） |
| 连不上 NapCat | `onebot.accessToken` 和 NapCat 里设的不一致（向导默认两边都留空） |
| 面板改了设置不生效 | 没点「保存配置」，或者没重启机器人 |
| 群里回得太积极 | 把「插话积极程度」调到 1 或 2 |
| 想省钱 | 把「判断用的模型」指向便宜模型（见下面双通道） |

### 双通道（省钱用）

可以给不同用途配不同模型 —— 比如回复用 DeepSeek，群里「要不要插话」的判断用本地模型：

```json
"llm": {
  "active": "deepseek",
  "purposes": { "reply": "deepseek", "judge": "openai" },
  "openai": {
    "baseUrl": "http://127.0.0.1:11434/v1",
    "model": "qwen3:4b"
  }
}
```

`baseUrl` 填到 `/v1` 为止。本地模型免费：

| 工具 | 地址 |
|---|---|
| Ollama | `http://127.0.0.1:11434/v1` |
| LM Studio | `http://127.0.0.1:1234/v1` |

> ⚠️ 用**本地纯文本模型**时，要去掉 `bot.vision.enabled`（本地小模型看不了图会报错）。

## 七、表情包

把图片丢进 `stickers/` 文件夹就能用。三种命名方式都会自动识别情绪：

```
stickers/笑死/01.gif        ← 按文件夹名
stickers/无语.jpg           ← 按文件名
stickers/[生气]骂人.png     ← 方括号显式标签
```

新丢进去的图**自动打标签**（用 AI 识别，结果缓存不重复花钱）。

**自动抓群里的表情包**：别人在群里发的图会被收进 `stickers/_自动抓取/`，去重、打标签后自己也能发。
收之前会先判断是不是表情包 —— 截图、照片、二维码会被丢掉。

## 八、小本本

机器人会给每个跟它说过话的人记一本笔记：

| 类型 | 什么意思 |
|---|---|
| `grudge` | 记仇（这人说过的难听话） |
| `favor` | 记好（这人对我不错） |
| `trait` | 性格印象 |
| `event` | 发生过的事 |

**它不是流水账**：只在「情绪波动」或「标志性事件」时才记，日常闲聊不记。

**防捏造是硬保证**：
1. 提示词强制要求**逐字照抄**对方原话
2. 程序校验那段引用**真的在对话里出现过**，编的直接丢掉并打日志

**说话策略**：攒够几条记录后，自动总结对这个人该怎么说话（语气 + 该做 + 别做）。

**面板「⑥ 小本本」页**能看每个人的记录、原话出处、策略，也能手动删掉记错的、补一条。

> 💡 **对号主是特殊对待的**：机器人对"你"和对"外人"用的是两套逻辑 —— 对你更亲近、可以委屈可以提要求，但**不会像对付外人那样直接怼回去**。

## 九、掉线了怎么办

**QQ 掉线是常态**（NapCat 属于非官方接入），先别慌。

### 怎么知道掉线了

机器人会**弹系统通知** + 在**桌面写一个告警文件**。也可以在面板「① 登录与配置」页看「掉线诊断记录」。

### 掉线分两种

| 表现 | 是什么 | 怎么办 |
|---|---|---|
| 3001 端口还在，但**好友列表是空的** | QQ 假在线（客户端崩了/被踢） | 重启 QQ |
| **3001 端口没了** | NapCat 挂了 | 重启 NapCat |

**最快的办法**：右键 `restart-qq-napcat.bat` → 以管理员身份运行。

### 想让它自己恢复

跑一次 `authorize-autorestart.bat`（右键管理员）。之后掉线时机器人会自动重启 QQ + NapCat，你只需要扫码。

### 掉线诊断是干什么的

每次掉线自动抓一份现场快照存到 `records/掉线诊断.log`：

- 系统上次启动时间
- 近 6 小时的睡眠/唤醒事件
- 近 6 小时的会话状态变化
- 网络适配器状态
- QQ / NapCat 进程及启动时间
- 3001 端口监听状态
- 自动睡眠设置、已用内存
- 近 2 小时系统错误

**为什么这个有用**：排查掉线原因时，事后翻日志基本没用（QQ 自己不会留记录），但现场快照能一眼看出是"睡眠导致的"还是"QQ 崩溃"还是"网络断了"。

## 十、成本参考

按 DeepSeek 官方价格（`deepseek-chat`）：

| 场景 | 量级 |
|---|---|
| 一段普通对话（几轮） | 约 0.001~0.005 元 |
| 一天聊 100 条 | 约 0.1~0.5 元 |
| 群里判断要不要插话 | 每次约 0.0001 元（只输出一个数字） |

**省钱办法**：
1. 把「判断用的模型」指向本地模型（判断次数远多于回复次数）
2. 把 `deepseek.maxTokens` 调小
3. 把 `deepseek.contextTurns` 调小
4. `bot.notebook.maxNotesInPrompt` 调小

**性能占用**：机器人大约 **60~70 MB 内存**，CPU 基本不动。

## 十一、常见问题

**Q：双击 `一键启动.bat` 一闪就没了 / 停在「找不到 Node.js」**
正常情况不会 —— 包里自带 Node，脚本会优先用它。
真报错的话，说明 `runtime\node\node.exe` 丢了，最可能的原因是**解压没解完**（有些解压软件遇到大文件会中断）。
重新解压一次，或者单独确认 `runtime\node\node.exe` 存在（约 90 MB）。

**Q：双击 `一键启动.bat` 弹「用户账户控制」，我点了否**
那就没法启动 NapCat（它要注入 QQ 进程）。重新双击，这次点「是」。

**Q：双击 `一键启动.bat` 后，机器人窗口里一直在刷 `ECONNREFUSED 3001`**
说明 QQ 还没登录成功。看桌面上的 QQ 登录窗口，扫码登录后它自己就会连上。
如果你已经登录了却还是刷，用 `fix-napcat.bat`（右键管理员）修一下。

**Q：双击 `restart-qq-napcat.bat` 提示「需要管理员权限」**
这是设计如此。**右键 → 以管理员身份运行**。NapCat 注入 QQ 必须要提权。

**Q：在面板里点「启动 NapCat」，点了没反应**
现在不会了 —— 面板会告诉你真实结果（起来了 / 没起来、为什么）。
如果它说「20 秒内没起来」：
1. 看屏幕上有没有「用户账户控制」，有就点**是**；
2. 还是不行就走最稳的路：**右键 `一键启动.bat` → 以管理员身份运行**。
（原理：面板如果是普通权限，就需要 UAC 授权才能注入 QQ；
如果面板本来就是管理员（从 `一键启动.bat` 起的），它会直接启动，不弹 UAC。）

**Q：打开 NapCat WebUI，让我填 Token，输什么？**
不需要自己找 —— 面板「① 登录与配置」页有一栏
**「NapCat WebUI 登录 Token」**，旁边点「复制」，粘进去就行。
（正常流程根本用不到这个 WebUI，它是给你排查问题用的。）

**Q：它说找不到 QQ**
先确认装了 **PC 版 QQ**（<https://im.qq.com/pcqq>）。
脚本是从注册表读 QQ 安装路径的，绿色版/免安装版 QQ 读不到，需要正常安装一遍。

**Q：机器人完全不回复**
检查 `config.json` 里 `bot.allowedUsers` 是不是空的，以及 `bot.enabled` 是不是 `true`。
再看黑窗口里有没有 `[onebot] connected` —— 没有就是没连上 NapCat。

**Q：连不上 NapCat**
① NapCat 起了吗（看 3001 端口）② `accessToken` 两边一致吗 ③ 是不是没扫码登录。

**Q：它到底有没有在线？**
**别看 `get_status`，它会撒谎。** 真正的判据是**好友列表非空**。面板上的状态检测用的就是这个。

**Q：电脑休眠了会怎样**
NapCat 会变成空壳进程 —— 进程还在、端口还开着，但收发全废，而且**不会自愈**。
这就是 `bot.keepAwake` 默认开着的原因。

**Q：能不能不用 DeepSeek**
可以。`llm.active` 改成 `openai`，`baseUrl` 指向任何 OpenAI 兼容服务（中转站、本地 Ollama、硅基流动等）。

**Q：会不会把我号封了**
有可能。**强烈建议用小号**。另外：别在群里回太积极（容易被群主踢/举报），别用主号加太多好友。

**Q：说的话会不会被记录**
聊天记录只有在「录制」开启时才存本地（`records/`），不会上传到别的地方。小本本也只存在本地 `notebooks/`。

**Q：这套东西占多少资源**
机器人本身约 **60~70 MB 内存**，CPU 基本不动；加面板一共 ~130 MB。
但**内置的 Node + NapCat 运行时**会各占几十 MB，QQ 本体另算。整体是个轻量工具，不是性能负担。

## 附：怎么暂停 / 恢复 / 关闭

| 想干什么 | 怎么做 |
|---|---|
| 临时不回消息 | 面板上点 **■ 停止机器人** |
| 彻底关掉 | 双击 `force-stop.bat` |
| 只在某时段工作 | 改 `bot.timeWindow`，把 `enabled` 设 `true` |
| 只让指定的人触发 | `bot.allowedUsers` 填 QQ 号，别用 `["*"]` |
| 关掉群聊 | `bot.group.enabled` 改成 `false` |

---

*想确认环境有没有问题又不想启动机器人：双击 `setup.bat` 时它开头就会自检一遍；
也可以在命令行里跑 `setup.bat --check`（只检查、不提问、不改任何文件）。*
